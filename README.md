## 🚀 Featured Projects & Products

Here is a look at some of the custom software solutions built by my studio:

### 🏆 Points Accumulation (Desktop & Web Versions)
An interactive system that gamifies student achievements and reward tracking.
Available in both standalone desktop and advanced web cloud versions, fully customizable to an institution's branding.
* **Flexible Hardware Integration:** Supports branded **RFID Smart Chips**, **Barcodes**, or **Magnetic Cards**.
* **Student Interface:** Users select completed tasks on-screen, scan their chip/card, receive points with real-time recognition, and print a physical receipt. Points can be redeemed for gifts and reward vouchers.
* **Advanced Web Features:** Includes daily/periodic challenges, attendance validation, pop-up random bonuses, surveys, and messaging channels.
* **Admin Dashboard:** Robust management interface with data visualization, customizable settings, and full Excel export capabilities.

### 🎰 Interactive Raffle & Lottery Engine
Designed to make prize drawings immersive and high-energy for large events.
* Implements dynamic visual countdowns, action-packed animations, and built-in sound effects (background music, applause, and cheers).
* Admins input the prize list, and the software automatically draws winners based on custom program parameters, ensuring an exciting and transparent drawing process.

### 🎁 Surprise Card Game System
An innovative, suspenseful reward program based on random ticket scanning.
* Distributed colorful barcode cards are scanned at a station.
* **Winning Scan:** Triggers impressive on-screen firework animations and reveals the specific prize.
* **Non-winning Scan:** Displays dynamic motivational messages to encourage future participation.
* Automatically generates and prints prize collection receipts.
